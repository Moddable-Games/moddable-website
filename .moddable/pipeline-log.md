This file records quality assessments of routine runs. Written by Triage after reviewing Research and Implementation output. It is the feedback loop that allows the pipeline to improve over time.

Read this at the start of every Desktop session and every Triage run.

## Format

Each entry covers one routine run. Triage writes entries for the Research and Implementation runs it is reviewing. Desktop sessions may add entries when reviewing merged PRs.

```
### {date} — {Routine name} — {Issue worked}
**Output:** [what was produced]
**Quality:** Pass / Fail / Partial
**Notes:** [what was good, what was thin, what was missing, scope creep, pattern violations]
**Action taken:** [sent back to research / merged / flagged needs-decision / etc]
```
