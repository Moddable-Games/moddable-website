Moddable.Games is a workshop publishing open-source rulebook mods for the board games already on your shelf, and three original games designed to be modded from day one.

The premise

Tabletop publishing is conservative. Rules are copyrighted, artwork owned, and trademarks defended. This leaves a lot on the table. Half the fun of a game is the way your group plays it, not the way the publisher intended.

We do two things. We write patches you can run with the components in the box you already own. No expansions to buy, no replacement parts to print, just a PDF and a flat surface. We also design original games whose entire rulebook is in a git repo so anyone can fork it.

The bigger picture

We're building the ecosystem tabletop games is still missing. A place where physical and online play converge under community ownership, with an online engine that hosts any hex-based game, a marketplace where designers sell mods and expansions, and instructive bots that learn from every game played.

The engine is live in open alpha. Print-on-demand is in progress. The marketplace follows. Every piece compounds: more creators means more players, which means better bots and more creators.

Open-source, always

Every rulebook lives in a git repo. Every game ships with moddable files. Swap factions, rewrite endgames, add new boards. We make the rules, the engine, and the community. The rest is yours.
